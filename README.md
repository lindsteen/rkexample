# Test af onlinekursus

Mobilvenlig webudgave af onlinekursus i psykisk førstehjælp.

## Filer

- `index.html` – hele kurset i én fil. HTML, CSS, JavaScript, forsidefoto og de tre lydklip (SE, LYT, LINK) er indbygget.
- `.nojekyll` – fortæller GitHub Pages, at siden skal udgives som den er.

Videoerne afspilles fra Vimeo. Videoerne med Jørgen, Hamid og Ulla hentes fra fabo.org.

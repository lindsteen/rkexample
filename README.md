# Psykisk Førstehjælp – onlinekursus

Mobilvenlig webudgave af Røde Kors' onlinekursus i psykisk førstehjælp.
Tekst og overskrifter følger kurset på fabo.org 1:1.

## Filer

- `index.html` – hele kurset i én fil. HTML, CSS, JavaScript, forsidefoto og de tre lydklip (SE, LYT, LINK) er indbygget.
- `.nojekyll` – fortæller GitHub Pages, at siden skal udgives som den er.

Videoerne afspilles fra Vimeo. Videoerne med Jørgen, Hamid og Ulla hentes fra fabo.org.

## Udgiv på GitHub Pages

1. Opret et nyt, offentligt repo på github.com og læg disse filer i det (fx med GitHub Desktop eller `git`).
2. Gå til **Settings → Pages**.
3. Under **Build and deployment** vælges *Deploy from a branch*, branch `main`, mappe `/ (root)`. Gem.
4. Efter cirka et minut ligger kurset på `https://<brugernavn>.github.io/<reponavn>/`.
